# طفلك هو البطل

مشروع واجهة React + TypeScript + Vite قابل للتعديل والتشغيل خارج المعاينة.

## التشغيل

تحتاج Node.js 20.19+ أو 22.12+ و npm.

```sh
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. لبناء نسخة استضافة ثابتة:

```sh
npm run build
npm run preview
```

ارفع محتويات `dist/` إلى استضافة مواقع ثابتة تدعم HTTPS. لا تفتح index.html مباشرة من الملفات.

## التعديل

- `src/App.tsx`: النصوص والأقسام والباقات والتجربة الصوتية.
- `src/style.css`: التصميم والألوان والاستجابة للشاشات.
- `src/contact.json`: روابط واتساب بالرسائل المحددة.
- `src/audio/`: حكايتان تجريبيتان MP3.
- `src/photos/`: صور الشخصيات الخيالية وأغلفة القصص.
- `src/covers.json`: رسوم أقسام القصص مضمنة.
- `src/fonts.json`: خطوط الواجهة مضمنة.

الباقات: 10 قصص = 500 جنيه، 20 قصة = 800 جنيه، 50 قصة = 1000 جنيه. الدفع بعد استلام التطبيق. لا توجد بوابة دفع أو نظام طلبات خلفي أو جمع بيانات أطفال.

زر «شاهد تجربة التطبيق» يفتح نافذة معاينة. اضغط التشغيل في المشغّل المباشر لسماع القصة. زر الاستماع في الصفحة يشغّل القصة ويعرض الحالة. قد تمنع بعض المتصفحات المدمجة تشغيل الوسائط؛ استخدم المشغّل المباشر أو متصفحًا مستقلاً عند الحاجة.

## قبل الإطلاق التجاري

هذه واجهة مراجعة، وليست تطبيق العميل النهائي. الشخصيات والأصوات والأمثلة خيالية. حقوق الاستخدام التجاري للأصول والأصوات واسم العلامة تحتاج مراجعة منفصلة، ولا يمنح هذا الأرشيف ترخيصًا تجاريًا لها. راجع أيضًا تراخيص الخطوط قبل التوزيع التجاري. حدد الأجهزة المدعومة وطريقة تسليم التطبيقات وبداية مدة التنفيذ وشروط الخدمة والخصوصية قبل فتح الطلبات.

روابط واتساب تفتح رسائل غير مرسلة. زر المقارنة يغير الاختيار مؤقتًا ولا ينشئ طلبًا. أزرار الاتصال موجودة في الصفحة، ولا تحتوي هذه النسخة على زر اتصال عائم ثابت على الشاشة.

## فحص سريع

- افتح الصفحة عند عروض 320 و390 و1280 بكسل.
- جرّب الحكايتين والتبديل والإيقاف والتقديم.
- افتح نافذة التجربة وأغلقها.
- راجع أسعار الباقات ورسائل واتساب دون إرسال تجريبي للعملاء.
- افتح الأسئلة الشائعة.

لا يتضمن المشروع أي مفاتيح أو حسابات أو قاعدة بيانات. أضف نطاقك وشروطك بعد اعتماد النسخة.
